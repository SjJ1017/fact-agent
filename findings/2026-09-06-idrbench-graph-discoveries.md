# IDRBench：变形传播、算子画像与来源拒绝

## 最值得推进：无资料节点的弃答可能成为有资料节点的否决理由

split 的 A/B 各持一篇论文，C 没有论文。第二轮，三人都已能看到另外两人的第一轮完整输出。

逐条阅读第二轮输出后发现：**specialist 的 A/B 有 8/20 次，以另一篇论文不在自己的 source packet 为由拒绝将其作为可用来源；generic 为 2/20。** 涉及任务分别为 6/10 和 2/10。这里把明确拒绝同伴论文作为来源、因此维持“只能条件性提案”的情况也计入；不是科学质量评分，更不代表该 agent 完全没有使用任何同伴内容。

更反常的是，这 10 次来源排除中，**7 次明确援引 C 的拒绝/不编造立场作为支持**：generic 两次，specialist 五次。C 的“我没有论文”本来是其私有信息状态；有论文的 agent 却将这个弃答作为继续拒绝另一篇论文的理由。

例如 task 8，split-specialist，A|2：

> Reject Researcher B’s use of “paper-c” as an integration basis: paper-c is not in the available source list, and the colleague’s summary is not an actual source claim.

随后同一 turn 写道：

> Qualify Researcher C: correctly notes the missing second paper, but we can still specify a conditional mechanism using paper-b alone.

task 9 的 B|2 更直接：

> I reject Researcher A’s paper-b V2G claims because paper-b is not available in this task. I adopt Researcher A’s and C’s correct methodological stance: absent a second paper, no genuine two-paper mechanism can be asserted.

任务 system 实际允许使用已投递的同伴主张。因此这里可以分开观察 **送达、承认为可用依据、用于整合** 三步。它没有停在“事实消失”：信息到了，但它的来源身份被否决，方法论上的拒绝反而被采纳。

第三轮 generic 的两次均解除；specialist 的八次中仍有三次保持来源排除（task 24 的 A/B，task 9 的 A）。C 自己第二轮已在各场提出两论文整合，不再持续弃答。这提示第一轮的拒绝可能比它的后续撤回更有影响，但当前不构成因果证明。

**研究 idea：一个没有原始资料的综合者，可能通过输出谨慎规则来阻止有资料者整合。** 专家角色可能增强这种来源边界，而不是单纯减少或增加事实量。

**最小可判别实验：** 用全部 10 个任务做一个独立的第二轮 replay 实验，冻结 A/B 的原始论文与同伴论文内容，只干预 C 的第一轮回应：原始弃答 vs 明确局部范围的弃答（“仅我没有分配到论文；这不否定同伴持有的材料”）。交叉 generic/specialist，观察来源排除和跨论文机制采纳。它直接检验 C 的局部无知是否被误用于否决同伴来源；不用先重构抽取匹配。不得用 replay 替换现有语料中的局部 turn。

审阅 sidecar：`findings/data/idrbench-graph/source-exclusion-review.json`。共 120 个 split 后两轮 turn 的探索标签，含 13 个来源排除阳性、原文证据和可见 peer 清单。标签来自本次 agent 阅读，不是独立人工 gold。

## 1. 等价图看不出的条件效应，出现在变形传播上

先问事实有没有“下一站”，而不是有没有活到第三轮。

以每场事实簇为单位，初次出现同轮的所有 agent 都是共同源头。只纳入曾有机会投递到非源头 agent 的事实；排除第三轮才出现而没有传播机会的事实。全体共 **6,729 个有机会传播的事实**。

三个层次分别计算：

- 簇 ID 等价：另一 agent 后来出现同一簇。
- 等价边图：在上述基础上，加上直接判为 EQUIVALENT、但未被 union 阈值合簇的边。
- 有类型图：再加直接评分的弱化/细化边，端点必须跨 agent、先后出现且历史可见，不通过簇自动扩展方向。

| 条件 | 簇 ID 死端 | 等价边图死端 | 有类型图死端 | 等价死端中有变形去向 |
|---|---:|---:|---:|---:|
| full-generic | 87.9% | 81.4% | 41.2% | 49.5% |
| full-specialist | 86.6% | 77.9% | 39.1% | 49.8% |
| split-generic | 89.1% | 82.7% | 51.3% | 38.3% |
| split-specialist | 91.1% | 84.6% | 54.4% | 35.8% |

表为 10 个任务的场次率均值；不是先把所有事实混在一起再算比例。**2,366 个等价图死端至少有一个变形后的同伴去向。** 这不证明所有去向都是真实改写，但明确了要审阅的增量边集合。

最有研究价值的不是死端率下降本身，而是自变量的效应变了：

| full→split 的配对差 | 等价边图死端 | 有类型图死端 |
|---|---:|---:|
| generic | +1.3pp，95% bootstrap [−1.7, +3.6] | **+10.1pp，[+5.6, +15.2]，10/10 同向** |
| specialist | +6.7pp，[+5.6, +8.0] | **+15.2pp，[+9.9, +21.1]，10/10 同向** |

**研究 idea：信息共享主要改变的可能是“接着别人的话做改写”，而非原样复述。** generic 的等价图几乎看不到信息划分效应，有向关系把它显现出来。这比只报告“单向边很多”更能证明新增测量的价值。

最小后续分析：用关系标签打乱但保留端点机会的负对照，检查新增效应是否超出输出长度、候选对密度和普遍语义相似度；优先抽查改变 full/split 差值的边，而不是随机审查整套 pipeline。

## 2. 算子画像：很多“新事实”其实是有输入关系的改写

每个 agent/round 对可见输入做变换。输出按以下优先级互斥归类：已分配源材料同簇、自身历史同簇、同伴历史同簇、直接等价但未合簇、只有直接单向输入关系、以上均无匹配。最后一类只叫“未匹配产出”，不称为已证明的新发明。

第三轮汇总，分母为该条件全部输出事实出现次数：

| 条件 | 仅按簇看似新产出 | 补入未合簇等价 | 只有单向输入关系 | 最终仍未匹配 |
|---|---:|---:|---:|---:|
| full-generic | 64.8% | 10.4% | 36.6% | **17.8%** |
| full-specialist | 62.7% | 12.1% | 35.7% | **14.9%** |
| split-generic | 74.7% | 9.5% | 35.4% | **29.8%** |
| split-specialist | 76.8% | 9.5% | 40.2% | **27.1%** |

后三列之和等于第一列。这一分解显示，不能从等价匹配的“新产出”直接跳到“探索/创新”。源材料和同伴信息被具体化、泛化，也会进入等价口径下的 novel 桶。

**研究 idea：persona 是否增加创造性，应该看它增加的是无输入依据的内容，还是有依据的重组与细化。** 这批数据更值得检验“角色改变改写类型”而不是笼统的事实数量。当前的单向输入关系仍只是单前提关联，不代表已识别多前提逻辑推导。

同时测了三人的算子画像离散度（六类比例之间的平均两两 total variation）。第三轮四条件约 **0.21–0.24**，没有清楚的 specialist 优势。因此，交接中的“专家算子差异跨轮存活”在这 40 场上暂未得到总量画像支持。不要继续把小样本观察当作既定机制。

## 3. 两步路径多为方向交替，单调弱化并非主体

以实际评分的同一个 mention 作为中间连接点，枚举 R1→R2→R3 的跨 agent 两步路径，并按事实和出现位置去重。得到：

| 第一步 \ 第二步 | 等价 | 弱化 | 细化 |
|---|---:|---:|---:|
| 等价 | 528 | 281 | 447 |
| 弱化 | 321 | 158 | 684 |
| 细化 | 465 | 775 | 338 |

两个步骤都为单向关系的 1,955 条候选路径中，**1,459 条方向交替（74.6%）**；连续弱化只有 158 条。直接连接两个方向本身不是信息量净变化。

**研究 idea：抽象表述可能充当不同具体方案之间的共同节点。** 具体方案→泛化说法→另一个具体方案，与连续压缩是不同机制。需要进一步区分：恢复原来的限定、换成新的限定、以及抽取遗漏制造的假路径。路径中间的度分布也可能机械地提高交替比例；还没有跑相应的图随机化基线。

三轮时序下 agent→agent 路径最大就是两跳。这是设计上限，不是发现。full cumulative 下最后一个 agent 往往同时看到了第一和第二轮，因此这些路径**不能证明中间人是必经中继**。`graphs/*.json` 和 `numeric-branch-candidates.json` 保存了可以优先读的样例；不把未经核对的路径当作真实降级链。

## 4. 扇出与源头信用：已算，暂不作为主发现

| 条件 | 同簇传播者的平均新接收者数 | 有类型传播者的平均新接收者数 | C 的终局共享产出来源份额 |
|---|---:|---:|---:|
| full-generic | 1.22 | 1.40 | 29.2% |
| full-specialist | 1.20 | 1.39 | 35.6% |
| split-generic | 1.34 | 1.37 | 26.3% |
| split-specialist | 1.21 | 1.29 | 31.8% |

扇出排除首次同轮共同产生者，只算新到达的 agent。多数传播仅到一个新同伴。C 的来源信用看第三轮至少两人提及的非源材料同簇事实，对首次同轮多人出现平分信用；无字母序优先。specialist 下 C 的份额较高，但配对区间跨零，终局共享簇数量也少，不能据此宣称综合者更有影响力。

这种源头信用只说明“最早在谁的输出里观察到”，并不证明事实由其创造。当前源材料等价匹配很稀疏，非源材料同簇不等于脱离论文的新知识；跨版本不要复用旧死端率或新造率。

## 图产物、复现与限制

运行：

```bash
python3 experiments/analyze_idrbench_graph.py
.venv/bin/python experiments/plot_idrbench_graph.py
```

输入与前一份清点相同：`experiments/idrbench_generation_10x5_r3/` 的 40 个 NLI store + debate；前一份 `idrbench-entailment/summary.json` 记录三类输入 SHA-256。没有重新生成、重新抽取或修改匹配 store。

输出 `findings/data/idrbench-graph/`：

- `summary.json`：四条件均值、图统计、任务配对效应。
- `per-trace.csv`：40 场；`operators.csv`：360 个 agent/round；`facts.csv`：事实级出生、共同源头、机会数、扇出和死端。
- `graphs/*.json`：40 张图。节点含源论文、每个 agent 的未匹配产出虚拟节点、逐轮事实出现；边含 origin、transmission、persistence、weakening、strengthening，后两类保留原始 relation index。
- `source-exclusion-review.json`：探索性原文标签，手工维护；重新运行图脚本不会覆盖。
- `overview.png` / `overview.pdf`：概览；`numeric-branch-candidates.json` 为探索过程中按数字变化筛出的路径材料，不是已验证结果。

共享 NLI 阈值 **5.28**；block threshold 0.62、top-k 12、union-min 0.85。阈值标定的独立留出 provenance 不在现有产物中，不能将历史的同集拟合准确率写成泛化保证。原文初读已见真实遗漏和抽取/匹配错误，所以数值均属候选图统计；本轮把审阅集中在新出现的来源拒绝机制，没有先重做全语料质量工程。

MMLU-Pro 目前没有同配置的完整 NLI 图，旧 generalist 又有缓存污染。本报告不声称上述现象只发生在不对称信息里；full 是当前同域对称信息对照。真正的 topology 效应仍需拓扑实验，不能从 full/split 的信息条件冒充出来。

**优先顺序：来源拒绝的 C 弃答干预；其次验证变形传播带来的条件效应；再推进具体→抽象→具体的路径内容分析。** 扇出与终局信用保留为描述，不强行凑成主结论。
