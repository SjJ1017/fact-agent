边的构成

把蕴含边按强弱两句的时间关系分成三类。只有第一类是关于「信息在传递中丢失」的断言。

没有专门的「泛化者」

如果某个座位系统性地把别人的事实说弱，它的净收支应该明显为正。实际不是。

一个必须先说的限制。「能看到」这个条件在 cumulative memory 下几乎不筛任何东西—— 9,202 条跨轮边里 0 条因为不可见被排除。所以降级边的含义是「弱版本更晚、且强版本当时在上下文里」， 不是「弱版本从强版本来」。要把它坐实成因果，需要能切断可见性的条件（peer-only 或 self-last 记忆）， 现有语料没有。

怎么读这些数

  • 划分信息降低降级，不是因为事实更少。四个条件的事实数在 2,285–2,506 之间，差异小于 10%， 而降级率差了 36%。
  • 降级链也变短：完整信息下平均最长链 3.3–3.4 跳，划分信息下 2.6–2.8。一条事实被反复削弱的 次数变少了。
  • 轮跨度几乎不变（1.12–1.29），说明降级主要发生在相邻轮次，不是跨越整场慢慢流失。
  • 跨 agent 比例 61–67%，其余是同一 agent 把自己上一轮的说法说弱了——那一类同样是降级， 而且不需要传递。

与 DelibTrace 的关系

DelibTrace 用 Jaccard 测事实存活，一条事实要么在要么不在。上面这 4,043 条降级边在那个框架里 只有两种记法：算作同一条（信息损失不可见），或算作两条不同（看起来像丢了一条又新造一条）。 两种都描述不了「还在但被削弱了」这个状态，而它占了非无关边的三分之一。
