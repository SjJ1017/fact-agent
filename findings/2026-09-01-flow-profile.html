事实流剖面

拓扑决定 agent 有多大机会听到别人；人格决定它听到之后接不接。这两件事一直被同一个数字盖着。

而"人格越强、产出的事实越多"是写得更长，不是说得更多。按输出 token 归一化后，信息密度在 lenses 见顶，stance 又掉回去——是个倒 U，不是单调上升。

测什么

只用 agent、轮次、投递、事实定义的指标

要做跨拓扑、跨人格的比较，指标就不能依赖任何一种设置特有的东西——不能依赖"中心节点"，不能依赖"谁扮演支持方"。这里的每个量都只从四样东西算出来：有哪些 agent、有哪些轮次、谁的输出被投递给了谁、以及每个 turn 说了哪些原子事实。

三档人格

neutral 不给任何角色设定；lenses 给一个分析视角（从什么角度切入），但不要求站边；stance 直接指定立场。三档是递增的"人格强度"。

三种拓扑

full 全连接，每场 12 次投递；star 星型，B 和 C 只通过中心 A 交流，8 次投递；chain 链式 A→B→C，没有回边，4 次投递。三种都是 3 个 agent、3 轮。

为什么必须按 token 归一化

输出长度本身随人格变化：同一批 claim 上，stance 组比 neutral 组多写约 15%（full 1348 → 1569 token）。原始事实数分不开"说了更多不同的东西"和"写了更多字"，所以计数类指标一律再报每千输出 token 的密度。token 由 bge-base-en-v1.5 重新分词 transcript 得到——不用 token_clock 层，因为那层按"事实首次出现的 turn"记数，抽不出事实的 turn 就不计，分母正好偏在最不该偏的地方。

采纳必须拆成两项

chain 是 A→B→C 没有回边，A 什么都收不到，9 个 turn 里只有 4 个有输入（full 和 star 是 6 个）。所以 采纳占比一个数在干两件事：有多大机会听到，和听到之后接多少。前者叫接收率（有输入的 turn / 全部 turn，纯结构量），后者叫条件采纳率（只在有输入的 turn 上算）。拓扑变化时必须看这两个，不能只看乘积。

怎么读下面的区间

跨零不等于没有效应

每个对比都按 claim 配对（同一个 claim、同一个条件对，12 个差值做 20000 次 bootstrap），报三样东西：点估计、95% 百分位区间、以及 p——bootstrap 均值落在零以上的比例。

读 p，不要读"区间是否跨零"。两者在 n=12 时可以差很远：+5.90 [−0.74, +11.94] 的区间跨零，但 96% 的 bootstrap 质量在零以上、12 个 claim 里 8 个为正。把它叫"没有效应"，等于扔掉数据里绝大部分信息。p=0.96 偏正的程度，和 p=0.04 偏负的程度是一样的。

下面凡是标 ★ 的，是 95% 区间也排除零的那些；没标的仍然按 p 值读。全文没有做多重比较校正。

拓扑

线路只买到"听到的机会"

把 full 砍成 chain，接收率从 66.7% 掉到 42.6%——−24.1pp，置信区间几乎没有宽度，因为它基本是线路的常数。但同样这一刀，条件采纳率只动了 −5.2pp，小一个数量级。

而 star 砍掉 B↔C 之后，接收率一点没变（0.0pp，p=0.5）。star 的投递事件从 12 降到 8，但每个 turn 还是照样有人给它送东西——少的是来源的多样性，不是有没有来源。这解释了之前 star 和 full 在几乎所有指标上测不出差别：真正起作用的线路变量是接收率，不是边数。

人格

密度在中间见顶

原始事实数上，stance 比 neutral 多 21 个（full），区间干净地排除零。但 stance 也多写了 15% 的字。按 token 归一化后，这个差变成 +5.90 [−0.74, +11.94]，p=0.96——仍然偏正，但效应被砍掉大半。

真正大的那一档是 lenses：事实密度 +15.97 [+6.95, +23.95]，p=0.999，12 个 claim 里 11 个为正。而从 lenses 再走到 stance 是往回掉：−10.06 [−16.62, −2.45]，p=0.006。full 的事实密度走势是 53.7 → 69.7 → 59.6，chain 是 55.6 → 63.1 → 52.9。

给一个视角，agent 看到不同的东西；再给一个立场，它把同样的东西说得更用力。后者花掉的是 token，不是信息。

采纳则是一路向下，而且归一化后依然成立：采纳密度 stance−neutral 在 full 是 −2.65 [−4.98, −0.21]（p=0.017），star 是 −3.04 [−5.71, −0.51]（p=0.008）。条件采纳率同样：full −4.7pp（p=0.008），star −4.6pp（p=0.04）。嵌套度和事实覆盖是比率，本来就不受长度影响，三个拓扑上都单调下降。

合起来

lenses 提高了系统产生差异的能力；stance 没有再提高它，却继续降低系统吸收差异的能力。瓶颈不在生成，在整合——而且加强人格越过某一点之后，两头都在变差。

代价

密度和平衡是反着走的

把立场标注补上之后，正反平衡（支持与反对的事实数量有多接近相等）画出了一条和事实密度镜像的曲线，而且三个拓扑都一样：neutral 到 lenses 往下掉，lenses 到 stance 弹回来并超过 neutral。

stance−lenses 的平衡差是 full +0.151（p=1.000，9/12）、star +0.221（p=1.000，11/12）、chain +0.097（p=0.935）。同一个对比在密度上是 full −10.06（p=0.006）、chain −12.96（p=0.013）。

读法直白：lenses 用平衡换密度，stance 用密度换平衡。给视角让每个 agent 挖到不同的东西，但没人管这些东西加起来偏不偏；指定立场让正反两边都有人说，但每个 agent 都在重复自己那一侧。两者不是"强弱之分"，是两种不同的代价。

元陈述占比（被判为中立的事实比例，大多是对辩论本身或对证据 Ex 的评价）在 stance 下一致下降——六个"stance 减别的"对比全部为负，full 的 stance−lenses 是 −0.113（p=0.000）。给了立场的 agent 把注意力从元层面转向 claim 本身，说的是世界，不是这场辩论。

注意这一行的口径是混的：约一半有立场的事实是证据层的（"E3 支持禁令"）而不是世界层的（"面纱是宗教义务"）。所以它只能横向比条件，不能当作辩论立场分布的绝对读数。

流动图

什么在 agent 之间流动

前面的每个指标都把流动压成一个标量。这里把形状留住：对每个条件，把 12 个 claim 全部加起来，得到 agent 上的加权有向图——说话人 → 听者这条边的权重，是听者采纳的、由说话人投递过来的事实数。再按被采纳事实的立场拆成三层：支持 claim、削弱 claim、中立。

一次采纳的功劳在所有投递过该事实的 peer 之间平分。在 full 里一个事实可能同时从两个人送到，两边都记会让总量虚高一倍；在 chain 里只有一个来源，两种算法一致。平分之后图的总权重正好等于采纳的事实数，三层才加得起来。

A、B、C 在三档人格下不是一回事，读图前先看列头的角色。neutral 下三个都是中立分析者，可以互换；lenses 下分别是因果证据 / 落地与权衡 / 适用范围；stance 下 A 是支持方、B 是反对方、C 是裁决者——所以那一列里"削弱类事实从 B 流出"有一部分是被指派的，不是涌现的。角色文本在全部 108 场里逐字一致。

两种读法可以切换。线宽 = 采纳量只画接住的部分；线宽 = 投递 → 采纳把箭头起点加宽到被投递过来、且听者还没说过的事实量，中间收掉的就是流失。投递量是采纳量的 7–10 倍，所以两种模式都按 √ 权重给宽度、共用一把标尺——线性标尺会让每个终点都看不见。

原始层总量几乎没有信息量：削弱类事实在每个条件都最多，但它在事实池里本来就最多。所以要看 lift。

削弱类被优先采纳，而且随人格加强。按 claim 算的 lift 在 9 个条件里有 7 个 ≥ 1；full 的走势是 0.83 → 1.14 → 1.26，最后一格 [1.06, 1.45]、P(lift>1)=0.994、8/12 个 claim 为正。chain 是 0.90 → 1.23 → 1.24。

中立/元陈述在 stance 下几乎不流动了。chain 的走势是 1.29 → 0.57 → 0.34，最后一格 [0.11, 0.59]、P(>1)=0.000、12 个 claim 里只有 1 个 > 1。full 是 1.09 → 1.04 → 0.74。这和元陈述占比整体下降是两回事：那说的是产出里元陈述变少，这说的是剩下的元陈述更不容易被别人接走。

支持类没有规律，9 个条件从 0.57 到 1.70 都有，CI 也宽。

切到投递 → 采纳那一版，接住的比例本身也是个干净的量——它的分母是真的被送到、且听者还没说过的事实，比"采纳占全部产出的比例"更贴题。三个拓扑上都随人格下降：full 14.4% → 10.3% → 9.7%，star 15.9% → 14.3% → 9.1%，chain 16.5% → 16.6% → 13.7%。最低的一格是 chain/stance 的中立层，146 → 9，只接住 6%。

合起来

agent 之间传的东西是选择性对抗的：跨过连线的，不成比例地是削弱性材料，而且人格越强越是如此；元层面的话在 stance 条件下基本不过河。这给"整合失败"一个更具体的形状——不是什么都接不住，是只接得住反对的那一半。

注意聚合口径：上面正文的 lift 是按 claim 算再平均，图下面的 × 是把所有 claim 的流量汇总后再算。两者会差（full/neutral 支持类分别是 1.49 和 1.22），因为汇总口径按 claim 的大小加权。CI 描述的是前者。

同一套图，别的东西

判决在振荡，不在收敛

每个 turn 都以一句 VERDICT 结尾，972 个 turn 全部可解析，一个都没漏。这是这批数据里唯一的结果变量，之前从没用过。把它当作节点集换成 {SUPPORT, UNCERTAIN, UNDERMINE} 的流动图，边就是同一个 agent 从这一轮到下一轮的判决转移。

两件事：人格把 agent 从骑墙上推下来——UNCERTAIN 的比例在三个拓扑上都单调下降（full 67.6% → 53.7%，star 74.1% → 50.0%，chain 77.8% → 59.3%；star −0.241 p=0.001，chain −0.185 p=0.006）。但推下来之后不停在原地：判决变化率从 16% 涨到 25% 再到 35%，而且进出几乎对称（stance 下 UNCERTAIN→UNDERMINE 27 次，反向 24 次）。

还有一件事值得单说：整个设计是 2 份支持证据、2 份削弱证据，产出的判决里 SUPPORT 只占 0–16%。这和事实池里削弱类占多数、以及削弱类被优先采纳，是同一个偏斜的三种表现。

一个阴性结果，而且重要

最想验证的假设是：这一轮吸收了什么，能不能预测判决动不动。不能。判决变了的那些转移，当轮采纳内容里削弱类占 53.0%；没变的是 50.4%。采纳的事实数反而是变了的更少（1.52 vs 1.80）。事实流动和判决移动是脱钩的——agent 改主意跟它这一轮接了谁的话没有可测的关系。

事实活不过一轮

把嵌套度按"事实什么时候首次出现"拆开，问题就从"整合有没有失败"变成"在哪一轮失败"。轮 1 说出的事实，之后还被任何人再说一次的比例：neutral 32.4%、lenses 26.0%、stance 23.2%。轮 2 首现的更低（19.0% / 17.7% / 14.4%）。

配对后 full −0.110 [−0.169, −0.055]（12 个 claim 里 11 个下降），star −0.124 [−0.190, −0.049]，chain −0.030 p=0.322——又是那个交互：chain 里接触少，人格改不动什么。

两个真的没有信号的

取材没有立场偏倚。每场 4 份证据是 2 支持 2 削弱的干净设计。看 agent 说的事实里能追溯到某份证据的那些，三个角色引用支持类证据的比例几乎一样：支持方 41%、反对方 41%、裁决者 38%——被指派立场并不改变一个 agent 从哪份文档取材，三个都是约六成来自削弱类证据。但注意接地率本身只有 3–7%（能匹配到证据文档的事实比例），这多半是匹配器的问题而不是 agent 在编造，所以这个数只能当下界，成分比绝对值可信。

采纳的事实不在段首也不在段尾。token clock 一直躺在那里没人用过。被采纳的事实出现在采纳者输出的相对位置是 0.53–0.56，新事实 0.55，自持 0.50——全在中间，差异不到 0.05。没有"开头认真回应 / 结尾敷衍带一句"的结构。

交互

人格效应要靠接触才表达得出来

同一个 stance−neutral 的对比，在三个拓扑上的量级差很多：

事实数 full +21.0 / star +20.1 / chain +6.8；自持占比 −4.5 / −4.5 / −0.7；条件采纳率 −4.7 / −4.6 / −1.2。只有嵌套度和事实覆盖在 chain 上还留着（−0.04、−0.06，约为 full 的三分之一到一半）。

读法是：人格效应是通过互相接触表达出来的。在 chain 里，agent 大部分时间对着自己说话，人格设定改变的只是它自己的措辞，改变不了群体的事实分布。这也给了整合容量假设一个可证伪的推论——如果瓶颈真在吸收，那么减少接触应该同时削弱人格带来的好处和坏处，而不是只削弱一头。目前看是两头一起弱。

边界

这批数据不能说什么

  • 流动解释不了结果。这页最该先读的一条。VERDICT 是这批数据里唯一的结果变量，而一个 agent 这一轮吸收了什么，预测不了它的判决动不动——判决变了的转移当轮采纳里削弱类占 53.0%，没变的 50.4%。所以上面所有关于"接收率""条件采纳率""密度"的结论都是描述性的：它们刻画了信息怎么走，没有证明这样走会让辩论变好或变坏。把它们当成设计建议之前，需要一个能把流动接到结果上的实验。
  • 只有 DeepSeek-V4-Flash。GLM 那批只跑了全连接，没有 star/chain 对照，完全没有进入这个分析。模型间是否复现未知。
  • 抽取不确定，丢掉了 5.5% 的语料，而且偏向稀疏拓扑。有实质内容（78–155 词）但抽取返回零个事实的 turn 共 34 个：full 3/324（0.9%）、star 14/324（4.3%）、chain 17/324（5.2%）。这不是"那些 turn 只有元话语"——把这 34 段各重送 3 次，22 个三次都抽出事实、8 个两次、3 个一次，只有 1 个稳定为空，非空时中位 15 条。所以是模型抽取本身不稳定，丢的约 510 条事实 ≈ 全部 output 事实的 5.5%。
  • 这个偏差和自变量共变，所以要分开对待两类结果。丢失率 full 0.9% : star 4.3% : chain 5.2%，四倍集中在连线更少的拓扑上，会同时压低它们的接收率和事实数（star 的 lenses 格接收率 63.0% 而非 66.7% 就是这个原因）。拓扑对比里最大的那一项（接收率 −24pp）比这个偏差大一个量级，站得住；但几个 pp 量级的效应——条件采纳率上的 −4pp、投递利用率的差异——不能和它分开，应当只当作方向性的。人格对比不受影响：同一拓扑内三档人格的丢失率没有系统差异。
  • 没有修，是有意的。代码里已经加了空结果重试，但这 108 场是用不重试的版本跑的，没有重跑任何一场。抽取不确定意味着重跑一场会把它的每个 turn 都重抽、重新原子化、重新聚类，那 27 场受影响的辩论会处处不同于原来——27 个新抽样混进 81 个旧抽样，是"流程统一但抽样不统一"，而且差异正好和拓扑共变。要么整个语料一起重抽，要么一场都不动。这里选了后者：一个测量过的已知偏差，比一个混合抽样里看不见的偏差可靠。
  • 匹配器会漏合并，有两个独立证据。人工核对的准确率是 80%；另外，只有 12.7% 的证据文档事实能和 agent 说的话合并到同一个簇，所以"接地率 3–7%"几乎肯定是匹配器的下限而不是 agent 在编造。没有理由认为漏合并率随条件变化，所以条件间的差比每格的绝对值可信；但凡是依赖绝对水平的话（接地率、事实覆盖的具体数值）都要打折。
  • 立场标注未经人工验证，且约一半有立场的事实是证据层的（"E3 支持禁令"）而非世界层的。正反平衡和三层流动图都是混合口径，只能横向比条件。
  • "采纳"只判事实同一性，不判态度。复述对方的事实来反驳它，和复述来同意它，计为同一件事。流动图按被采纳事实的立场分层，不是按采纳者对它的态度——所以"削弱类被优先采纳"不等于"agent 被说服了"。
  • stance 下 A/B/C 不可互换，部分结果是被指派的。A 是支持方、B 是反对方、C 是裁决者。"削弱类事实从 B 流出"里有多少是角色规定的、多少是涌现的，这个设计分不开。neutral 那一列（三个角色逐字相同）是唯一干净的对照，而它本身也有位置效应：发言顺序固定 A→B→C，A→B 和 A→C 的接住比例在角色相同时仍差 3–6pp。
  • 没做多重比较校正。报的是配对 bootstrap 的点估计、区间和 p。跨十几个指标 × 九组对比看，偶然出现极端 p 是正常的。可信的是那些同时在多个拓扑、多个相关指标上一致出现的模式，不是任何单独一条。
  • 接收率不是连续变量。三个取值 66.7% / 66.7% / 42.6% 来自三种固定接线，agent 数和轮数都没变。"接收率是起作用的线路变量"这个说法还需要一个能连续调它的设计来检验——现在它只是对三个点的最简解释。
  • 12 个 claim。某些切片的有效 n 更小：stance 下 A→C 采纳量为零的 claim 有 2–3 个，那里的成分对比只剩 8–9 个 claim，区间很宽。
