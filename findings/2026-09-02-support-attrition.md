# 每个 agent 都在丢弃支持性证据，包括被指派为支持方的那个

2026-09-02。数据 `findings/data/context-output.json`，脚本
`experiments/analyze_context_output.py`（离线，不调模型）。
deepseek-v4-flash，108 场，918 个 turn。

## 做法

把 agent 当成一个有输入侧和输出侧的节点：

```
context(a, r) = 从证据文档抽出的事实 ∪ 投递给 a|r 的同伴 turn 说过的事实
output(a, r)  = a|r 自己说出的事实
```

两侧用同一套 SUPPORT / UNDERMINE / NEUTRAL 标注，所以两个立场构成可以直接比。
差值（`tilt`，百分点）就是一次**选择**：在它能重述的全部东西里，它选了说什么。

**上下文不限于卷宗。** 第 1 轮它只有卷宗，从第 2 轮起主要是同伴说过的事实——问的是
agent 拿到*任何*正反材料时会怎么取舍。主结果是全部 918 个 turn；按轮也分开报，
用来看这个倾斜是一次性反应还是每轮都在发生。注意后面几轮的基线是同伴上一轮的输出，
那已经被压过一次，所以数值变小**不等于**漂移在减速。

## 对照：卷宗本身是平衡的

立场标注器和文档设计一致，所以倾斜不是从材料继承来的：

```
E1（设计为支持）  SUP 70.9%    E3（设计为削弱）  UND 70.6%
E2（设计为支持）  SUP 69.0%    E4（设计为削弱）  UND 77.7%
卷宗整体          SUP 40.9%  UND 44.7%  NEU 14.5%
```

## 结果（全部 918 个 turn，★ = 确信度 ≥ 0.975）

```
条件      角色           SUP 入 → 出            UND 入 → 出
neutral   全部      30% → 20%  ★  −9.7     43% → 47%  ★ +4.3
lenses    全部      24% → 16%  ★  −7.5     50% → 53%    +2.8
stance    全部      30% → 23%  ★  −7.1     48% → 52%  ★ +3.8

stance    支持方    31% → 25%  ★  −5.7     50% → 49%    −0.7
stance    反对方    31% → 23%  ★  −7.4     47% → 52%  ★ +5.7
stance    裁决者    29% → 21%  ★  −8.3     48% → 55%  ★ +6.6
```

九个（人格 × 角色）格的 SUPPORT 下降**全部**达到确信度 0.975。按轮拆开也每轮都在
（neutral：−14.2 / −9.4 / −5.5，三轮确信度都是 1.000）。

## 三条结论

**一、支持性材料被系统性丢弃，这是模型层面的，不是人格造成的。**
neutral 面板的三个 agent 提示词逐字相同，仍然把 SUPPORT 从上下文里的 30% 压到
输出里的 20%（−9.7pp，确信度 1.000）。人格设定并没有制造这个偏斜，它本来就在。

**二、人格能减弱这个漂移，但挡不动方向。**
支持方是 SUPPORT 掉得最少的角色（−5.7，对比反对方 −7.4、裁决者 −8.3），
也是唯一一个 UNDERMINE 没有上升的（−0.7，确信度不足）。角色提示确实起作用——
但它买到的是**减速**，不是把天平推向支持侧。

**三、裁决者比反对方还要更偏。**
UNDERMINE 上升幅度是裁决者 +6.6、反对方 +5.7；而裁决者本应是中立的。
"比较双方证据"的角色提示没有让它比反对方更平衡。

## 这解释了此前几个悬着的观察

- **VERDICT 里 SUPPORT 只占 0–16%**（`2026-09-02-fact-flow-report.html` 第九节），
  尽管卷宗是 2 支持 2 削弱。现在知道结论层的偏斜在事实层就已经形成了。
- **削弱类事实被优先采纳**（同一份报告第八节，lift 1.26）。采纳只是这个更一般的
  倾向在传播环节的表现。
- 正反平衡在 stance 条件下反而最高——因为支持方把 SUPPORT 守住了，而其他两个角色
  在往下压，两边抵消之后群体层面反而更均衡。

## 局限

- **跨 channel 合并只有 4.4%**（见 `fix.md` 缺陷五），所以 context 里的卷宗事实和
  output 事实基本是两个不相交的集合。这里比的是两个**分布**，不是子集关系。
  分布比较仍然成立，但"这条具体的事实被丢了"无法逐条追踪。
- 立场标注未经人工核对；约一半有立场的事实是证据层而非世界层。
- 后面几轮的倾斜量级小于第 1 轮（neutral −14.2 / −9.4 / −5.5），
  这**不是**说漂移变慢了，而是基线已经被上一轮压低了。
- 只有 deepseek-v4-flash。GLM 未做此分析。

## 下一步

这个结果把研究问题从"人格是否增加多样性"推向一个更具体的问题：
**为什么模型在平衡材料上系统性偏向削弱？** 可检验的方向：

1. 换命题极性——如果把命题改写成否定式（"不应当禁止"），偏斜是否跟着翻转？
   翻转说明是"倾向于反驳给定命题"，不翻转说明是内容层面的偏好。
2. 去掉 VERDICT 要求，看事实层的偏斜是否仍在。现在无法排除是输出格式诱导的。
3. 单 agent 对照：一个 agent 读同一份卷宗写一段评估，倾斜多大？
   这能把"辩论"这个设定的贡献和模型本身的先验分开。
