事实流剖面

人格越强，agent 产出的事实越多，被别人接住的越少。全连接和星型都是如此。

而把全连接砍成星型——投递事件从 12 降到 8，少了三分之一的连线——在所有流动指标上都测不出效应。人格这个旋钮拧得动事实流，拓扑这个旋钮在这个规模下拧不动。

测什么

只用 agent、轮次、投递、事实定义的三族指标

要做跨拓扑、跨人格的比较，指标就不能依赖任何一种设置特有的东西——不能依赖“中心节点”，不能依赖“谁扮演支持方”。这里的每个量都只从四样东西算出来：有哪些 agent、有哪些轮次、谁的输出被投递给了谁、以及每个 turn 说了哪些原子事实。

一、token 预算的去向

把每个 turn 说出的事实分成三堆，互斥且穷尽：新事实（自己没说过、也没在收到的内容里出现过）、自持（自己上一轮说过）、采纳（首次出现在自己嘴里，但已经在收到的投递中出现过）。采纳占比就是采纳 ÷ 三者之和——一个 agent 的产出里有多大比例是在接别人的话。

二、流动图的形状

把“事实从 a 流到 b”当作有向加权边。嵌套度是 agent 之间事实集合的平均包含率，衡量他们说的东西有多重叠；事实覆盖是每个事实平均被几个 agent 说出（3 个 agent，上限 3.0）；流量基尼衡量流量是均摊在所有连线上还是挤在一两条上；投递利用率是有多大比例的投递事件真的搬动了至少一个事实。

三、事实群体本身

元陈述占比是被判为中立的事实比例——大多是对辩论本身或对证据 Ex 的评价，而不是对世界的断言。正反平衡是 1 − |n₊ − n₋| / (n₊ + n₋)，1 表示支持与反对的事实数量相当。

主结果

人格梯度：产得更多，接得更少

从 neutral 到 lenses 到 stance，人格设定越具体，产出的事实越多——全连接下多 21 个，星型下多 20 个。但这些多出来的事实并没有进入共享池：嵌套度、事实覆盖、采纳占比全部单调下降，而且两种拓扑上是同一个方向、同一个量级。

下降的不止采纳。自持占比同样单调走低（全连接 15.5% → 10.9%，星型 12.7% → 8.2%，两边 CI 都不含零）——人格越强，agent 连自己上一轮说过的事实都更少重提。采纳和自持是产出里仅有的两种“回头”，两个一起塌，意味着 stance 条件下的输出几乎全是新生成。

均值可能被少数几场辩论带偏，所以下面按 claim 配对：同一个 claim、同一个拓扑，stance 减 neutral，再对 12 个差值做 bootstrap 置信区间。这样每个 claim 自己当自己的对照，主题难度的差异被消掉了。

读法

嵌套度在全连接下 12 个 claim 里只有 2 个上升，星型下只有 1 个。这不是均值被拉动，是几乎每一场辩论都朝同一个方向走。

阴性结果

拓扑什么都没动

星型把 B 和 C 之间的连线拿掉了：每场辩论的投递事件从 12 降到 8。按直觉这应该显著削弱事实的传播。但把同一个 claim、同一个人格下的星型减全连接，24 个对比里有 23 个的置信区间跨过零。唯一的例外是 stance 下的自持占比（−0.027，[−0.053, −0.002]）——在一次没有做多重比较校正的 24 次比较里，这正是最不该单独相信的那种区间。

这有两种读法，现在的数据分不开。一是拓扑真的不重要：3 个 agent、投递从 12 减到 8，还不足以让信息传播受限——每个 agent 仍然直接看到中心节点，间接内容照样能两跳传到。二是拓扑效应被人格效应的方差淹没了：人格的效应量在 0.5–1.0 个标准差量级，拓扑若只有 0.2，12 个 claim 检不出来。要分开需要更极端的拓扑（chain 正在跑）或更多 claim。

解释

整合容量，而不是多样性不足

常见的多 agent 设计假设是：给 agent 不同的人格/视角，能拓宽搜索、覆盖更多角度。这批数据的前半段支持这个假设——人格确实带来更多事实。后半段不支持：多出来的事实留在了产生它的那个 agent 身上。事实覆盖从 1.33 掉到 1.17，意味着在最强人格下，一个事实平均只被 1.2 个 agent 说过——大多数事实从头到尾只有一个人提。

把这两半合起来，瓶颈不在生成多样性，而在整合多样性。系统能产出的差异，超过了它能吸收的差异。加强人格拓宽了输入端，同时收窄了吸收端——因为一个有立场的 agent 更倾向于说自己的话，而不是接对方的话。

自持占比同时下降是同一件事的另一面。一个 agent 不重提自己上一轮的事实，也不接别人的事实，就意味着每一轮都在开新话题——辩论在横向铺开，而不是在纵向收敛。这样的轨迹里没有可供收敛的公共基底。

这也解释了流量基尼为什么在 stance 下最高（全连接 0.400、星型 0.413）：少数几条连线承担了绝大部分实际搬动的事实，其余连线名义上通着，实际是空转。投递利用率同时下降，说明这不是流量重新分配，是流量整体变稀。

边界

这批数据不能说什么

  • 只有 DeepSeek-V4-Flash。GLM 的那批只跑了全连接，没有星型对照，所以完全没有进入这个分析。模型间是否复现未知。
  • 星型有 14 个空 turn（占 4.3%，全连接只有 0.9%）。这些 turn 有实质内容（93–128 词）但抽取返回零个事实。人格分布均匀，位置上外围 10 : 中心 4，大致按人数比例，所以不系统偏向某个条件——但它会同时压低星型的事实数和采纳数，是拓扑阴性结果的一个待排除解释。
  • 立场标注未经人工验证。而且已知约一半有立场的事实是证据层的（“E3 支持禁令”），不是世界层的（“面纱是宗教义务”）。正反平衡这一行因此是混合口径，只能横向比条件，不能当作辩论立场分布的绝对读数。
  • 事实匹配的人工核对准确率是 80%。剩下 20% 的错误会同时影响采纳、嵌套、覆盖——但没有理由认为错误率随条件变化，所以条件间的差比每格的绝对值可信。
  • 没做多重比较校正。这里报的是配对 bootstrap 置信区间，不是校正后的显著性。跨 7 个指标 × 6 组对比看，偶然出现一两条不含零是正常的。人格梯度可信是因为它同时在两个独立拓扑上、在四个相关指标上、以 10/12 到 11/12 的一致方向出现，不是因为某一条 CI。
  • “采纳”只判事实同一性，不判态度。一个 agent 复述对方的事实来反驳它，和复述来同意它，在这里计为同一件事。这是有意的——先量流动，再谈方向——但意味着采纳占比不能直接读成“达成共识”。
  • chain 拓扑还在抽取中。补上之后会有第三个拓扑点，也是三个里连线最少的，对上面“拓扑真的不重要”这个读法是最直接的检验。
