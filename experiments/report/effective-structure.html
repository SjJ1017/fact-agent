有效结构：预算、位置效应核查与中继

把多智能体辩论的每一句话拆成原子事实、按内容跨发言者对齐之后，我们能测量“信息在系统里到底怎么流动”。三个结果：具体人格把预算从复用推向新生，但这条梯度只在 full/star 清楚，到了低接触的 chain 几乎消失；一个看似显著的“先发言者主导终局”效应在三种拓扑下都经不起分解——它由破平局规则和共享材料池伪造；星型中心也不是有效中转站，真正经过中心的跨枝干传输每场不到一条。

本页自含：§1 描述实验本身，§2 定义后面用到的每一个指标与统计口径，§3–§7 是结果（每张图都说明数据、坐标与读法），§8 是局限。所有数字只来自“每个 turn 说了哪些事实、谁把哪一轮输出投递给了谁”这两样东西。

实验设置

一场辩论长什么样

数据来自 Perspectrum 测试集里的 12 个真实争议命题（如“公共建筑的宗教符号必须被禁止”）。每个命题配一份材料卷宗：命题本身 + 4 条人工策展的证据（2 条支持、2 条反对，标注了出处）。三个 agent（A、B、C）围绕这个命题辩论 3 轮；每轮每个 agent 输出一段 ≤180 词的评估，末尾必须给一行 VERDICT: SUPPORT | UNDERMINE | UNCERTAIN。材料人人可见且完全相同——没有私有信息。

轮次与可见性（“投递”）

第 1 轮三人并行生成、互不可见（提示词要求 “before seeing other panelists”）。第 2 轮起，每个人都只看到自己收到的上一轮 peer 输出——具体是谁，由拓扑决定，并且每一轮都记录在案（称为投递）：

  • 全连接（full）：每人看到另外两人的上一轮输出。每场 12 次投递。
  • 星型（star）：A 是中心——A 看到 B、C；B、C 只看到 A。每场 8 次投递。B 和 C 之间从不直接可见。
  • 链式（chain）：A→B→C，无回边。A 不接收 peer 输出，B 只看 A，C 只看 B。每场 4 次投递。

人格（persona）

三种对 panel 的提示词干预，只在“你是谁”上不同：neutral 三人都是“中立证据分析师”（提示词逐字相同，是唯一完全对称的对照）；lenses 三人分别用因果证据、实施与权衡、范围与不确定性三种认知透镜；stance 三人分别是支持方、反对方、中立裁决者。人格 × 拓扑 = 9 个条件，每条件 12 个命题，共 108 场。

事后测量（不回流）

辩论结束后离线做四件事，结果从不进入 agent 的提示词：抽取（把每句话拆成自包含的原子命题）、原子化（拆分并列句、剥离“E1 声称…”这类归属外壳）、匹配（跨 agent、跨轮次把表达同一命题的说法归并成一个规范事实，id 稳定）、标注（给每个事实标立场 SUPPORT / UNDERMINE / NEUTRAL，相对命题而言）。全部分析只依赖每轮说了哪些规范事实 + 投递记录。

范围。辩论与立场标注用 DeepSeek-V4-Flash；抽取/原子化/匹配用 minimax-m2.5。另有 33 场 GLM 全连接辩论，无拓扑对照，不进本页。star/chain 有少数空抽取 turn（见 §8）。

定义与统计口径

后面用的每个数，先在这里定义

流动与结构指标

  • 预算分解新事实 / 自持 / 采纳。把每个“agent 在某轮说出一个（规范）事实”的事件，按它的来源互斥且穷尽地分成三类：新事实＝自己以前没说过、也不在收到的投递里出现过；自持＝自己以前说过；采纳＝自己以前没说过、但已在收到的投递里出现过（即“别人说的，被我说了”）。三类占比合计 100%。
  • 采纳-保留收益被采纳的事实里，活到最终轮的占多少。采纳的“回头”是否真的进入终局组合。
  • 事实覆盖每个事实平均被几个 agent 说过。3 个 agent，上限 3.0。1.2 ≈ 大多数事实只有一个人提。
  • 嵌套度两两 agent 事实集合的平均包含率。把 A、B、C 各自说过的全部事实看作三个集合，两两算“较小集合被较大集合覆盖的比例”后取平均。0 = 各说各话，1 = 完全重复。
  • 有效独立数 n_effpanel 实际相当于几个互相独立的发声者。先算两两 Jaccard 相似度（交集 ÷ 并集），排成 3×3 矩阵，取其特征值 λ 并算参与比 n_eff = (Σλ)² / Σλ²。三人事实完全一样 → 1；完全不一样 → 3。它回答“三票赞成到底是不是三份独立证据”。
  • 唯一来源回声率被 ≥2 个 agent 说过的共识事实里，只有一个人是在它首次出现的轮次就说的比例。其余是随后读到才跟上的“回声”。0 = 每条共识都多方独立推出；1 = 所有共识都只有单一源头。
  • r1→r3 存活 / 峰值保留第 1 轮说过的事实里活到第 3 轮的比例；以及“终局轮活着的 ÷ 曾同时活着的峰值”——衡量系统自己淘汰自己的程度。
  • 数字存活第 1 轮出现过的数字字面量（如 12.3%）里，原样出现在第 3 轮输出中的比例。提取器被要求逐字抄数字，所以数字漂移 ≈ agent 自己改写的。

位置效应的核查口径（§4 用）

“谁先说出某个事实”只有在不同轮次之间才谈得上先后；第 1 轮是并行的，同轮只能说“谁也是首发者”。以下四把尺子都只统计终局组合（第 3 轮还活着的事实）：

  • obs credit“第一说出者”记账，同轮按名字 A<B<C 破平局。这是最容易算、也最容易伪造的量——同轮并行说同一件事时按名字把功劳判给 A。
  • exp credit同轮首发者之间平分功劳。与 obs 之差就是纯破平局伪影。
  • gen不看先后，只看“该 agent 在第 1 轮（并行、互不可见）有没有说过这个事实”。衡量的是生成而非传播。
  • uniq终局组合里从头到尾只有一个人说过的“唯一性事实”，按那个人记账。它没有破平局问题（只有一个人），但混着最后一轮的新生成。

星型中继口径（§5 用）

  • C→B（同理 B→C）统计 C 在第 1 轮说过的每个事实，B 的处置：从未＝B 任何一轮都没说；并行巧合＝B 也在第 1 轮说了（两人各自从同一份材料推出，与传播无关）；疑似中继＝B 只在第 2/3 轮说了（星型下这是上界——B 也可能自己重新推出）；实中继＝疑似中继里 A 明确在 B 之前说过（星型里 B 唯一可能看见该事实的通道）。
  • 沿用率收到的投递事件里，真的导致了对方说出 ≥1 个新事实的比例。

结论层（§6 用）

  • VERDICT每轮每人的结论行，972 个里全部可解析。终局一致率＝第 3 轮三人结论完全相同的场次占比；r1 多数 = 终局多数＝第 1 轮两人以上的一致结论，与第 3 轮多数结论相同的场次占比——衡量辩论到底改没改判。
  • 同侧采纳立场 panel 里，把“采纳”按事实的立场和采纳者的人设分组：支持方（A）采纳支持类事实、反对方（B）采纳反对类事实，称为同侧。随机底线＝投递给该 agent 的事实里本方立场占比——若采纳不做立场过滤，实测应约等于底线。

统计口径（全文通用）

  • 配对差值凡事提到“lenses − neutral”或“star − full”，都是同一个命题的两种条件相减（题目难度自己消掉），得到 12 个差值；汇总三个 persona 比较拓扑时得到 36 个差值。
  • bootstrap 置信区间对这组差值有放回重采样 20000 次，取 2.5%–97.5% 分位作为 95% 区间。* 表示区间不含零，即方向在 12 个命题上稳。未做多重比较校正：值得信的是跨两个独立拓扑一致出现的模式，而不是单条区间。
  • η²（§7）把 108 场按 9 个条件格分组，条件格均值能解释的方差比例＝组间离差平方和 ÷ 总离差平方和。0–1；接近 0 表示该指标在 n=12 采样下几乎全是命题内变异。
九个条件的读数，每格 = 12 场均值。份额与比例为占比；“事实覆盖”上限 3.0；“n_eff”上限 3.0；两行“一致率”= 12 场中达标场次 ÷ 12。“终局·首现于 rN”= 终局组合（第 3 轮还活着的事实）中首次出现在第 N 轮的比例。

结果一

人格梯度依赖接触：full/star 清楚，chain 几乎消失

把每场辩论的全部表述按“新事实 / 自持 / 采纳”记账（§2 定义），九个条件的占比见图 1。full 与 star 从 neutral 到 stance 都把预算从“回头”推向新事实；但 chain 没有复制这条梯度。

stance − neutral 在 full 下是 novel +0.077*、adopted −0.032*、held −0.045*；star 下是 novel +0.075*、adopted −0.030、held −0.045*。到了 chain，三项分别只有 +0.009 / −0.002 / −0.007，区间全部跨零。人格不是一个脱离交互环境的固定主效应：agent 很少收到同伴输出时，“更坚持自己的新话”也就没有多少可替代的复用预算。

有效独立数 n_eff是例外：stance − neutral 在 full/star/chain 分别为 +0.102* / +0.123* / +0.055*。即使连线很少，角色提示仍能让三人的事实集合更不相似；但只有在有充分接触时，这种差异才同时表现为更少采纳和更少自持。

结果二 · 核查

“先发言者主导终局”不成立：一个被口径伪造出来的效应

初版分析按“第一说出者”给终局组合里的每个事实记账（§2 的 obs），得到全连接 neutral 下 A 占 0.46、C 只占 0.24 的表观差异——A 看似“垄断”了终局。逐项分解后这个差异消失，由三块拼成：

  • 约一半是破平局伪影。第 1 轮三人并行说出同一事实时，按名字把功劳全部判给 A。exp（同轮平分）下的差异只有 0.117，而 obs 是 0.221。
  • 第一轮生成本身对称。gen（A 与 C 在第 1 轮各自踩中的终局事实份额）之差只有 0.023。材料人人可见 + 第一轮并行，“谁先开口谁踩中更多”在生成层面不成立。
  • 剩余部分是噪声。唯一的真实残余在“唯一性事实”（uniq），但它在方向上不稳定：集中在第 3 轮、由 12 个命题中的 2 个拉动（去掉后反转）、在条件间翻符号（full/stance 下 C 反超），内容多为“E1 没有提到 X”这类无证据性表述。

另外，采纳也没有稳定的位置优势：以全部第 1 轮独有事实为分母，full/neutral 中 A→他人是 0.25、C→他人是 0.17，但在更强方向性核查 chain/neutral 中反转为 0.19 对 0.26；上游 A 与下游 C 的 exp credit 差为 −0.018，gen 差为 −0.009。结论：在这个共享材料的规模上，测量不到跨拓扑稳定、可影响他人内容的位置优势。任何 first-utterer 类统计，在并行生成 + 共享池下都容易被破平局规则和有限事实池伪造出来。

顺带修正一个相关印象

三种拓扑合起来，终局组合里 69% 的事实是第 3 轮才首次出现的，第 1 轮的只占 17%。这与 §6 的结论层稳定性并不矛盾：结论常在第 1 轮就定了，事实组合却一直换血到最后一轮。

结果三

星型的中心不是中转站

星型里 B、C 互不可见，唯一的沟通通道是中心 A。按 §2 的中继口径统计（12 场汇总，neutral）：C 第 1 轮说过 144 个事实，B 从未说过其中的 100 个（69%）；B 也在第 1 轮并行说过的 22 个是巧合（两人各自从同一份材料推出）；B 只在第 2/3 轮说出的 22 个里，A 明确先于 B 说过的 14 个实中继——即每场约 1 条。B→C 方向更弱：74% 从未出现，实中继每场不足 1 条。

也就是说：跨枝干的表观重叠几乎全是共享材料下的巧合或独立重推，真正经过中心的传输是零星事件。名义图的边大多空转。这与全连接对照的行为一致——全连接下每人能收到两人，但采纳占比也只有 10% 上下（图 1）；差别在于星型把这点传输里的 B↔C 方向直接拿掉了。星型 − 全连接的配对差（36 个命题对，§2 口径）里，只有预算分解一项稳：novel +0.040*、adopted −0.020*、held −0.020*——收窄视野让系统更少复用、更多新生成。

结果四

结论在第一轮定，事实在最后一轮换

用每轮每人必须给出的 VERDICT（SUPPORT / UNDERMINE / UNCERTAIN，全部 972 个 turn 可解析）看结论层：第 1 轮多数结论与第 3 轮多数结论相同的场次占 67%–92%——大多数辩论不改判。而上一节刚看到终局事实大部分是最后一轮新生成的：理由池换了，立场常没变。

第 3 轮三人一致率呈 full 92/83/83%、star 67/67/33%、chain 75/67/50%（neutral/lenses/stance）。最低点仍是 star/stance，而不是边更少的 chain/stance；因此不能把它简化成“连线越少越分裂”。更像是立场分工与谁处在汇聚位置的交互，但每格只有 12 场，且角色与位置绑定，只能作为下一轮实验的候选结果。

结果五 · 负结果

采纳没有回声室过滤

立场 panel 里逐采纳者比较“同侧采纳率”与“随机底线”（§2 定义）：底线是投递给该 agent 的事实里本方立场占多少——若 agent 只接自己人的话，实测应显著高于底线。实测贴着或低于底线：full 的 B（反对方）同侧 0.72 对底线 0.67；star 的 A、B 0.29 / 0.60 对 0.32 / 0.61；full 的 A（支持方）同侧只有 0.15 对底线 0.31——方向甚至是欠采纳本方。

结合结果一：立场隔离是生产端的（各说各的、不接对方），不是接收端的过滤（对方的事实送来了照收）。chain 里只有 B（反对方）具备可比较的极化输入，实测同侧 0.57 对底线 0.58；A 没有输入，不能参与该检验。样本偏小（每格 20–50 次采纳），作为方向引用。

结果六

哪些指标真的带着信号：η²

把 108 场按 9 个条件格分组，η²（§2 定义）后，采纳占比最高（0.31），其次是新事实占比（0.25）与事实覆盖（0.16）。chain 把可见机会砍掉，因此“采纳”现在成了最能区分条件的量。回声率（0.03）和采纳-保留（0.06）仍主要是命题内变异。这里的 η² 只说明条件格与指标共同变化，不把拓扑和 persona 的主效应、交互效应分开。

边界

这批数据不能说什么

  • 只有一个模型进拓扑比较。辩论与标注都是 DeepSeek-V4-Flash；GLM 的 33 场只有全连接、无星型对照，未进本页。
  • 抽取缺失随拓扑变化。有实质文本但抽取返回零事实的 turn：full 3/324（0.9%）、star 14/324（4.3%）、chain 17/324（5.2%）。这会压低 sparse topology 的事实数和采纳数；VERDICT 直接从原始 transcript 解析，不受该缺失影响。
  • 共享材料是全部“巧合”的来源。三人读同一份卷宗，跨 agent 重叠天然高，且与真实传输不可分——所以本页一切传输结论都以投递记录为准，实中继口径（A 必须先说）是下界。
  • 立场标注未经人工核对（由模型自标），接纳-回声室样本每格仅 20–50 次，方向级证据。
  • agent 位置没有轮转。neutral 面板里三人提示词相同、身份可交换，位置核查在它上面成立；严格的因果结论（尤其 stance/lenses 与位置纠缠）需要角色-位置轮转的实验。
  • 没有人类答案可对照。VERDICT 只能测方向与一致性，不能测对错；命题-证据的覆盖（gold coverage）这条线仍被 add_gold 的 bug 卡住，本页没有一个“事实有用性”指标。
  • 没做多重比较校正。可信的是跨两个拓扑一致出现的模式（人格梯度、预算分解）与结构性零结果（位置、中继），不是单条区间。
  • 角色与位置仍绑定。chain 里 A 无前驱、C 只见 B，但 stance 条件同时把 A/B/C 固定成支持方/反对方/裁决者。只有 neutral 的位置比较是干净的；要估计纯拓扑效应，下一轮必须轮换角色位置。
