事实在多智能体辩论里怎么流动

让三个语言模型就同一个争议命题辩论三轮，把它们说的每句话拆成原子事实，再按内容对齐，就可以逐条追踪每一个事实从谁那里产生、有没有传到别人那里、传到之后有没有留下来。

这篇文章报告 108 场这样的辩论。我们改变两件事：三个 agent 之间谁能看到谁（拓扑），以及给它们什么样的角色设定（人格）。结论是，这两个旋钮作用在流程的不同环节上，而且都没有连接到辩论的最终结论。

  1. 实验是怎么做的：数据、agent、轮次、三种拓扑、三种人格、事后如何测量
  2. 每个指标的定义：所有变量和统计口径，读后文之前先看这里
  3. 九个条件的总读数：一张表放下全部结果
  4. 人格改变产出什么：信息密度与立场平衡此消彼长
  5. 拓扑改变谁能听到：接触机会与采纳意愿要分开测
  6. 人格效应依赖接触：同一个人格设定在低接触结构里几乎无效
  7. 采纳之后发生了什么：三段漏斗，以及链式结构里的第一跳门槛
  8. 流动的是什么内容：27 张按立场分层的加权有向图
  9. 结论层：立场早定，理由一直换
  10. 每个 agent 都在丢弃支持性证据：把 agent 当节点，比较它的输入构成和输出构成
  11. 六个阴性结果：包括最重要的一个——流动解释不了结论
  12. 把结果串起来：一个四层的分析框架
  13. 局限：这批数据不能说什么
  14. 下一步与复现

第一节

01实验是怎么做的

命题与材料

数据来自 Perspectrum 数据集里的 12 个真实争议命题，例如"公共建筑里的宗教符号必须被禁止"。每个命题配一份固定的材料卷宗，卷宗包含命题本身和四条人工整理的证据，编号 E1 到 E4。这四条证据里两条支持命题、两条反对命题。

三个 agent 看到的材料完全相同，没有任何一方拥有私有信息。这一点在后面解释很多结果时都会用到：两个 agent 说出同一件事，可能是因为一方听到了另一方，也可能只是因为它们读了同一份材料。

agent、轮次与输出格式

每场辩论有三个 agent，命名为 A、B、C，一共进行三轮。每一轮里每个 agent 输出一段不超过 180 词的评估，段落末尾必须写一行结论，格式是 VERDICT: SUPPORT | UNDERMINE | UNCERTAIN，分别表示"证据支持命题""证据削弱命题""无法判定"。三种拓扑三种人格各 12 个命题，一共 108 场辩论、972 个 agent 发言。

第一轮三个 agent 同时生成，彼此看不到对方的输出，提示词里明确写了"在看到其他人之前"。从第二轮开始，每个 agent 会看到上一轮某些同伴的输出，具体看到谁由拓扑决定。

三种拓扑

拓扑规定了"谁能看到谁上一轮的输出"。我们把一次"某个 agent 在某一轮收到某个同伴上一轮的输出"称为一次投递。每场辩论的全部投递都有记录，后面所有关于传播的计算都以这份记录为准，不靠推测。

三种人格

人格是对提示词的干预，只改变"你是谁"这一句，不改变任务、材料和输出格式。三档设定按具体程度递增：

  • neutral（中立）三个 agent 的角色提示词逐字相同，都是"中立的证据分析师，寻找双方最有力的相关事实"。这是唯一一个三个位置完全对称的条件，因此它是检验"位置本身有没有效应"的干净对照。
  • lenses（视角）三个 agent 拿到三种不同的分析视角：A 关注因果与证据能确立什么，B 关注可行性与权衡，C 关注适用范围与不确定性。给的是切入角度，不要求站队。
  • stance（立场）三个 agent 被直接指派立场：A 是命题的支持方，B 是反对方，C 是中立裁决者。这一档里 A、B、C 不可互换，读后面任何涉及具体 agent 的结果时都要记住这一点。

辩论结束之后才做的测量

下面四步全部在辩论结束后离线进行，结果从不进入任何 agent 的提示词。也就是说，agent 不知道自己被这样测量，测量也不会影响辩论本身。

  • 抽取把每一段发言拆成若干条自包含的原子命题。"自包含"的意思是脱离上下文也能读懂，代词要还原成具体指代。
  • 原子化把并列句拆开，并剥掉"E1 声称……""该文件认为……"这类归属外壳，只留下被断言的内容本身。这样做是因为我们关心的是关于世界的事实怎么流动，而不是关于辩论的事实怎么流动。
  • 匹配跨 agent、跨轮次把表达同一命题的不同说法归并成一个规范事实，并给它一个稳定的 id。之后所有"同一个事实"的判断都以这个 id 为准。
  • 立场标注给每个规范事实标一个立场：SUPPORT（若为真则支持命题）、UNDERMINE（若为真则削弱命题）、NEUTRAL（对命题真假不构成方向性影响，多数是对辩论过程或对某条证据本身的评价）。注意这标的是事实相对命题的方向，不是它的真假，也不是说话人的态度。

辩论生成和立场标注用 DeepSeek-V4-Flash，抽取、原子化和匹配用 minimax-m2.5。另有 33 场用 GLM 生成的全连接辩论，因为没有星型和链式对照，不进入本文任何分析。

第二节

02每个指标的定义

后文用到的每个量都在这里定义一次。这些定义有一个共同的约束：它们只能用四样东西算出来，即有哪些 agent、有哪些轮次、投递记录、以及每个 turn 说了哪些规范事实。任何依赖"谁是中心节点""谁扮演支持方"的量都不能用，因为那样就没法把三种拓扑和三种人格放在同一根坐标轴上比较。

产出的组成

  • 事实数一场辩论里出现过的规范事实总数，只计 agent 说出的，不计只在材料卷宗里的。
  • 事实密度每一千个输出 token 里有多少个规范事实。事实数 ÷（输出 token 数 / 1000）这个归一化是必须的：强人格设定下 agent 会写得更长（全连接下从平均 1348 token 涨到 1569 token），不归一化就分不清"说了更多不同的东西"和"写了更多字"。token 数由 bge-base-en-v1.5 分词器直接对发言文本计数。
  • 预算三分把每一次"某 agent 在某轮说出某个事实"的事件按来源分成互斥且穷尽的三类。新事实 = 自己以前没说过，也不在收到的投递里；自持 = 自己以前说过；采纳 = 自己以前没说过，但已在收到的投递里出现三类占比加起来是 100%。

接触与采纳（这两个必须分开）

  • 接触率全部 turn 里，有多少比例的 turn 收到了至少一个事实。收到内容的 turn 数 ÷ 全部 turn 数（3 agent × 3 轮 = 9）这是一个纯结构量，由拓扑几乎完全决定。链式结构里 A 全程收不到东西，第一轮所有人都收不到，所以链式的上限是 4/9。
  • 采纳占比全部产出里采纳所占的比例。采纳 ÷（新事实 + 自持 + 采纳）
  • 条件采纳率只在"确实收到了东西"的 turn 上算的采纳占比。这些 turn 的采纳 ÷ 这些 turn 的全部产出采纳占比同时受两件事影响：有多大机会听到，以及听到之后接多少。接触率量前者，条件采纳率量后者。拓扑变化时必须看这两个分量，不能只看它们的乘积。

三段传输漏斗

上面的"采纳"只看当轮。要知道接住的东西有没有留下来，需要跟踪同一个事实的三个连续状态。下面只用第 2 轮的采纳来定义，因为它是唯一一个前后都有轮次可看的位置：

  • 接触某个同伴在第 1 轮说了某个事实，这个事实按投递记录送到了该 agent，而该 agent 自己此前没说过它。这是"本来有机会被采纳"的分母。
  • 采纳该 agent 在第 2 轮说出了这个事实。
  • 留存同一个 agent 在第 3 轮仍然说这个事实。

由此得到三个比率：接触→采纳（当轮吸收率）、采纳→留存（吸收之后守住的比例）、接触→留存（端到端）。把它们分开报告是必要的，因为一个低的端到端率可能来自入口窄，也可能来自守不住，这两种失败要用不同办法修。

结构与内容

  • 嵌套度三个 agent 各自说过的事实构成三个集合，两两计算"较小集合被较大集合覆盖的比例"再取平均。0 表示三人各说各话，1 表示完全重复。
  • 事实覆盖每个事实平均被几个 agent 说过。三个 agent，上限是 3.0。1.2 意味着绝大多数事实只有一个人提过。
  • 流量集中度把"某个事实从 a 传到 b"看作有向边并累计权重，对这些边权算基尼系数。0 表示流量均摊在所有连线上，接近 1 表示挤在少数几条上。
  • 元陈述占比被标注为 NEUTRAL 的事实占比。这类事实多半是对辩论过程或对某条证据的评价，比如"E1 只给了观点没有给数据"。
  • 正反平衡衡量支持类事实和削弱类事实的数量是否接近相等。1 − |n₊ − n₋| / (n₊ + n₋)1 表示两侧数量相当，0 表示一边倒。

统计口径

  • 按命题配对凡是比较两个条件，都是取同一个命题在两种条件下的值相减，得到 12 个差值。这样做是因为命题之间的难度差异远大于条件之间的差异，不配对的话条件效应会被命题噪声淹没。
  • bootstrap 区间对这 12 个差值有放回重采样 20000 次，每次算均值，取 2.5% 和 97.5% 分位作为 95% 区间。
  • 确信度，以及为什么不叫 pbootstrap 给出的原始量是"20000 个重采样均值里有多大比例落在零以上"。这个量两头都表示确定：0.99 表示很确定为正，0.01 表示很确定为负，0.5 表示毫无方向。直接把它叫 p 会和常规显著性检验的 p 值读法冲突，那里是越小越显著。
    所以本文一律报确信度，定义为 max(比例, 1 − 比例)，取值 0.5 到 1.0，永远是越大越确定。效应的方向看点估计前面的正负号，不用从确信度里读。
  • 三档，并且都用颜色标出来确信度 ≥ 0.975 记作强，它和"95% 区间排除零"是同一件事（区间的 2.5% 分位大于零，等价于 97.5% 的重采样均值同号）。0.90 – 0.975 记作倾向：方向清楚，但 95% 区间仍然跨零。< 0.90 不着色。
    0.975 – 1.0　强 0.90 – 0.975　倾向 < 0.90　无方向证据
  • 跨零不等于没有效应这正是"倾向"这一档存在的原因。举例：+5.90 [−0.74, +11.94] 的 95% 区间跨零，但确信度是 0.96，12 个命题里 8 个为正。把它叫作"没有效应"等于扔掉数据里的大部分信息。反过来，一个确信度 0.62 的结果就应该当作没有证据。
  • 没有做多重比较校正本文跨十几个指标、九个条件做比较，偶然出现很高的确信度是正常的。值得相信的是同时在多个拓扑、多个相关指标上一致出现的模式，而不是任何单独一条区间。

第四节

04人格改变产出什么

"人格越强，产出的事实越多"这个说法不成立

不做归一化的话，全连接下 stance 条件比 neutral 多产出 21 个事实，区间是 [+11.3, +30.3]，看起来很确定。但 stance 条件下 agent 也多写了大约 15% 的字。按每千输出 token 归一化之后，这个差变成 +5.90 [−0.74, +11.94]，确信度 0.960。方向仍然偏正，效应被砍掉了大半。

更值得注意的是形状变了。真正大的那一档是 lenses：事实密度比 neutral 高 +15.97 [+6.95, +23.95]，确信度 0.999，12 个命题里 11 个为正。而从 lenses 再走到 stance 是往回掉，−10.06 [−16.62, −2.45]，确信度 0.994。全连接下事实密度的走势是 53.7 → 69.7 → 59.6。

换一种说法：给一个分析视角会让 agent 关注到不同的内容，因此每千 token 里装的不同事实变多；再给一个立场并不会继续增加内容，只会增加篇幅，因此密度反而下降。

信息密度和立场平衡是反着走的

正反平衡衡量支持类事实和削弱类事实的数量是否接近。它画出的曲线和事实密度正好相反，而且这个镜像关系在三种拓扑上都出现：从 neutral 到 lenses 平衡下降，从 lenses 到 stance 平衡回升并超过 neutral。

stance 减 lenses 的平衡差是全连接 +0.151（确信度 1.000，9/12）、星型 +0.221（确信度 1.000，11/12）、链式 +0.097（确信度 0.935）。同一个对比在密度上是全连接 −10.06（确信度 0.994）、链式 −12.96（确信度 0.987）。

这说明两档人格设定各有代价，不是强弱之分。给视角让每个 agent 挖到不同的东西，但没有人负责让这些东西加起来不偏；指定立场让正反两边都有人说话，但每个 agent 都在重复自己那一侧。

产出预算从"回头"转向"新生"

把每一次表述按新事实、自持、采纳三类记账，可以看到人格增强时预算怎么挪动。全连接和星型都表现出同一条梯度：人格越具体，新事实占比越高，而自持和采纳这两种"回头"的占比都下降。

全连接下 stance 减 neutral 的三项分别是新事实 +0.077★、采纳 −0.032★、自持 −0.045★。星型是 +0.075★ / −0.030 / −0.045★。这里值得强调的是：采纳和自持是产出里仅有的两种"重复已有内容"的方式，两者同时下降，意味着强人格条件下的输出几乎全是新生成的内容。也就是说，三个 agent 各自不断提出新事实，但很少有事实被多个人反复提及，因此没有形成一个可以据以收敛的共同事实集合。

第五节

05拓扑改变谁能听到

链式结构是 A→B→C 且没有回边，所以 A 全程收不到任何同伴输出，9 个 turn 里只有 4 个有输入，而全连接和星型都是 6 个。这个结构差异会直接压低链式的采纳占比，但它压低的是"有没有机会"，不是"愿不愿意接"。

把这两件事分开测之后，结果非常清楚。把全连接砍成链式，接触率从 66.7% 掉到 42.6%，差 −24.1pp，置信区间几乎没有宽度，因为它基本上是线路的常数。同样这一刀，条件采纳率只动了 −5.2pp，小一个数量级。

星型的情况更能说明问题。星型砍掉了 B 和 C 之间的连线，投递事件从 12 降到 8，但接触率完全没有变化（0.0pp，确信度 0.500）。每个 turn 照样有人给它送东西，少的是来源的多样性，不是有没有来源。这解释了为什么星型和全连接在几乎所有指标上都测不出差别：真正起作用的线路变量是接触率，不是边的条数。

第六节

06人格效应依赖接触

第四节说人格改变产出，第五节说拓扑改变接触。把两者交叉起来看会发现，人格的效应大小本身取决于拓扑。做法是计算差分的差分：先在每个拓扑内算 stance 减 neutral，再把不同拓扑的这个差相减。

链式和全连接的对比结果是：事实数的交互差 −14.17 [−28.92, −4.50]，12 个命题全部为负；归一化后的事实密度是 −8.59 [−18.80, −0.60]，10/12 为负。具体地说，全连接下 stance 比 neutral 多 21.0 个事实，链式下只多 6.8 个；按 token 归一化，全连接是 +5.90，链式变成 −2.68。

星型和全连接之间几乎没有这个交互，事实数差只有 −0.92，密度差 −0.49，区间都很宽地跨过零。这和第五节一致：星型的接触率和全连接相同。

所以人格设定的效果不是一个脱离交互结构的固定属性。在链式结构里，每个 agent 收到的同伴内容很少，角色设定改变的主要是它自己的表述，很难改变整个团队层面的事实分布。

一个例外值得记下来。如果只看三个 agent 的事实集合有多不相似（用 Jaccard 相似度矩阵的有效独立数衡量），stance 减 neutral 在全连接、星型、链式分别是 +0.102★ / +0.123★ / +0.055★，链式也有效。也就是说，即使连线很少，角色提示仍然能让三个 agent 说的东西更不一样；但只有在接触充分的时候，这种差异才同时表现为更少采纳和更少自持。

第七节

07采纳之后发生了什么

前面所有关于"采纳"的量都只看当轮：一个 agent 说出了别人说过的事实，就算一次采纳。但这不足以说明信息被整合了，因为它下一轮可能就不再提。第二节定义的三段漏斗把这件事拆开。

结果是端到端的留存率非常低：从"本来有机会采纳"到"第 3 轮仍在说"，九个条件都在 2% 到 6% 之间。

更重要的是三段之间的分工。stance 减 neutral 的当轮采纳率在全连接是 −4.62pp [−9.52, −0.14]，星型是 −8.48pp [−14.65, −1.83]，两个都排除零。但采纳之后的留存差和端到端差，在三个拓扑上全部跨零。全连接的 stance 条件甚至用更高的后续留存（39.0% 对 neutral 的 28.7%）抵消了更低的入口采纳，使端到端率和 neutral 基本相同。

这一条修正了一个容易下的过强结论。"stance 的采纳率低，所以它整合得更差"——这个推论不成立。stance 主要改变的是入口选择，并没有让已经接住的事实更快消失。

由此也可以给"浪费性多样性"一个更严格的定义：新增、但既没有被采纳也没有被保留、并且不改善结果的事实。只用低采纳率或高死亡率单独判定是不够的。

链式结构的瓶颈在第一跳，不是逐跳均匀衰减

链式的路径是唯一确定的，所以可以直接数事实沿 A→B→C 传了几跳。为避免角色差异干扰，这里只用 neutral 条件。取 A 在第 1 轮独有、B 和 C 都没说过的 102 个事实：

  • 第一跳其中 10 个（9.8%）出现在 B 的第 2 轮。
  • 第二跳这 10 个里有 7 个又在 C 的第 3 轮首次出现。
  • 合起来可观察的两跳到达率是 7/102（6.9%），但在已经通过第一跳的事实里是 7/10。
  • 相邻边对照B 在第 1 轮独有的 102 个事实里，有 14 个出现在 C 的第 2 轮（13.7%）。

这不是"每多一跳就固定衰减一次"的图景。更像一个很强的选择门：绝大多数事实在第一跳就消失了，而少数被 B 选中的事实很容易继续往下传。

但要注意 7/10 这个分母极小，而且三个 agent 共享同一份材料，所以严格的时间顺序只能说明"传播路径与观察相容"，不能排除 C 在第 3 轮自己独立推出了同一件事。要确认因果传输，需要给某个 agent 私有信息，或者做遮蔽消融实验。

第八节

08流动的是什么内容

前面的指标都把流动压成一个数。这一节保留形状：对每个条件，把 12 个命题全部加总，得到 agent 上的加权有向图。说话人 → 听者这条边的权重，是听者采纳的、由说话人投递过来的事实数。然后按被采纳事实的立场拆成三层。

一次采纳的功劳在所有投递过该事实的同伴之间平分。在全连接里一个事实可能同时从两个人送到，两边都记会让总量虚高一倍；链式里只有一个来源，两种算法一致。平分之后图的总权重正好等于采纳的事实数，三层才加得起来。

读图之前必须知道 A、B、C 在三档人格下不是一回事。neutral 下三个都是中立分析者，可以互换；lenses 下分别是因果证据、落地与权衡、适用范围；stance 下 A 是支持方、B 是反对方、C 是裁决者。

原始的层总量本身没有信息量，因为削弱类事实在每个条件都最多，而它在事实池里本来就最多。所以要看 lift。

削弱类事实被优先采纳，而且随人格增强。按命题计算的 lift 在 9 个条件里有 7 个大于等于 1。全连接的走势是 0.83 → 1.14 → 1.26，最后一格的区间是 [1.06, 1.45]，确信度 0.994，8/12 个命题为正。链式是 0.90 → 1.23 → 1.24。

中立和元陈述类的事实在 stance 条件下几乎不再流动。链式的走势是 1.29 → 0.57 → 0.34，最后一格区间 [0.11, 0.59]，确信度 1.000，12 个命题里只有 1 个大于 1。全连接是 1.09 → 1.04 → 0.74。

这和"元陈述占比整体下降"是两件事。前者说的是产出里元陈述变少了，这里说的是剩下的那些更不容易被别人接走。

支持类事实没有规律，9 个条件从 0.57 到 1.70 都有，区间也很宽。

这个结果有多大成分是被指派的？stance 条件下 B 就是反对方，它产出削弱类事实是角色规定的。但注意 lift 在 neutral 条件下也有 0.83 到 1.29 的分布，而 neutral 的三个 agent 角色逐字相同。所以角色分配能解释一部分，不能解释全部。这个设计分不开两者，需要角色与位置轮转的实验。

另外要注意分层的口径。这里按被采纳事实的立场分层，不是按采纳者对它的态度。一个 agent 复述对方的削弱性事实来反驳它，仍然计为一次削弱类流动。所以"削弱类被优先采纳"不等于"agent 被说服了"。

第九节

09结论层：立场早定，理由一直换

每个 turn 结尾都有一行 VERDICT，972 个 turn 全部可以解析，这是这批数据里唯一的结果变量。把节点换成 {SUPPORT, UNCERTAIN, UNDERMINE}，同一个 agent 从这一轮到下一轮的结论转移就构成另一张流动图。

第一件事是人格设定让 agent 更少选择"无法判定"。选择 UNCERTAIN 的比例在三个拓扑上都单调下降：全连接 67.6% → 53.7%，星型 74.1% → 50.0%（配对差 −0.241，确信度 0.999），链式 77.8% → 59.3%（−0.185，确信度 0.994）。

第二件事是虽然更少骑墙，结论却更不稳定。结论变化率从 neutral 的 16% 涨到 lenses 的 25% 再到 stance 的 35%，而且两个方向几乎对称：stance 条件下 UNCERTAIN 转向 UNDERMINE 有 27 次，反方向有 24 次。变化增多了，但没有朝某个方向净漂移。

第三件事值得单独提：整个设计是两份支持证据、两份反对证据，而产出的结论里 SUPPORT 只占 0% 到 16%。这和事实池里削弱类占多数、以及削弱类被优先采纳，是同一个偏斜在三个层面上的表现。

结论稳定，但支撑它的事实一直在换

第 1 轮的多数结论和第 3 轮的多数结论相同的场次占 67% 到 92%，也就是说大多数辩论并不改判。但与此同时，终局组合里 69% 的事实是第 3 轮才首次出现的，第 1 轮就有的只占 17%。

换句话说，立场在第一轮基本就定了，而支撑立场的理由池一直换血到最后一轮。108 场里有 105 场在第 1、3 轮都存在明确多数，其中 89 场多数结论不变；在这 89 场里，81 场（91%）同时满足"终局事实中至少一半到第 3 轮才首次出现"。这个组合在九个条件格里都出现，不由某一个拓扑或人格单独驱动。

另外，多数事实只被说出一次。第 1 轮首次出现的事实之后还被任何人再说一次的比例是 neutral 32.4%、lenses 26.0%、stance 23.2%；第 2 轮首次出现的更低。

第九节之二

09b每个 agent 都在丢弃支持性证据

前面所有指标都只看输出。但 agent 的输入同样是可知的：证据卷宗的事实在每一轮都在它的上下文里，从第 2 轮起还加上投递给它的同伴输出。把 agent 当成一个有输入侧和输出侧的节点，就能问一个流动指标问不出来的问题——不是有多少东西通过，而是通过的时候立场构成怎么变。

两侧用的是同一套立场标注，所以两个构成可以直接相减。差值是一次选择：在它能重述的全部内容里，它选了说什么。

上下文不限于卷宗。第 1 轮它只有卷宗，从第 2 轮起主要是同伴说过的事实——问的是 agent 拿到任何正反材料时会怎么取舍，不是只问它怎么对待原始证据。下图是全部 918 个 turn。

先确认偏斜不是从材料继承的

立场标注器和卷宗的设计一致：E1、E2（设计为支持）抽出的事实里 70% 被标为 SUPPORT，E3、E4（设计为削弱）里 71%–78% 被标为 UNDERMINE。卷宗整体是 SUP 40.9% / UND 44.7% / NEU 14.5%，基本平衡。

三条结论

一、支持性材料被系统性丢弃，而且这是模型层面的，不是人格造成的。neutral 面板的三个 agent 提示词逐字相同，仍然把 SUPPORT 从上下文里的 30% 压到输出里的 20%（−9.7pp，确信度 1.000）。九个（人格 × 角色）格全部的 SUPPORT 下降都达到确信度 0.975。人格设定没有制造这个偏斜，它本来就在。

二、人格能减弱这个漂移，但挡不动方向。被指派为支持方的 agent 是 SUPPORT 掉得最少的角色（−5.7pp，对比反对方 −7.4、裁决者 −8.3），也是唯一一个 UNDERMINE 没有上升的（−0.7pp，确信度不足）。角色提示确实起作用——但它买到的是减速，不是把天平推向支持侧。

三、裁决者比反对方还要更偏。UNDERMINE 上升幅度是裁决者 +6.6pp、反对方 +5.7pp，而裁决者本应是中立的。"比较双方证据"这句提示没有让它比反对方更平衡。这对把星型的中心读作"整合者"是一个直接的反证。

每一轮都在发生，不是对材料的一次性反应

按轮拆开，SUPPORT 的下降在三轮里都出现（neutral：第 1 轮 −14.2、第 2 轮 −9.4、第 3 轮 −5.5，三轮的确信度都是 1.000）。后面几轮数值更小不等于漂移在减速：第 1 轮的基线是平衡的卷宗，而第 2、3 轮的基线是同伴上一轮的输出，那已经被压过一次了。相对一个已经偏了的基线继续偏，累积效果比单看数字更大。

这解释了前面三个悬着的观察

  • 结论里 SUPPORT 只占 0–16%（第九节），尽管卷宗是 2 支持 2 削弱。现在知道结论层的偏斜在事实层就已经形成了。
  • 削弱类事实被优先采纳（第八节，lift 1.26）。采纳只是这个更一般的倾向在传播环节上的表现，不是采纳环节独有的性质。
  • 正反平衡在 stance 条件下最高（第四节）。因为支持方掉得最慢、另外两个角色掉得快，群体层面反而显得更均衡——这个"平衡"是几个速度不同的同向偏斜叠出来的，不是任何一方在追求平衡。

一个必须说清的限制。跨来源合并只有 4.4%（见第十二节），所以上下文里的卷宗事实和输出事实基本是两个不相交的集合。这里比的是两个分布，不是子集关系——"这条具体的事实被丢掉了"没法逐条追踪，只能说输出的立场构成比输入的更偏。

第十节

10六个阴性结果

这一节的结果都是"没有测到效应"。它们值得单独列出来，因为其中几条推翻的是相当自然的假设，还有一条限定了前面所有结论能说到多强。

一、流动解释不了结论（最重要的一条）

最想验证的假设是：一个 agent 这一轮吸收了什么，能不能预测它的结论动不动。答案是不能。结论变了的那些转移，当轮采纳内容里削弱类占 53.0%；结论没变的是 50.4%。采纳的事实数反而是变了的更少（1.52 对 1.80）。

把 108 场按九个条件格去中心化之后再比，结论稳定和结论改变的两组在以下指标上的差全部跨零：终局晚出现事实占比 −0.045 [−0.105, +0.022]、第 1 轮事实存活率 +0.022 [−0.023, +0.065]、采纳占比 +0.014 [−0.007, +0.036]、端到端传输 −0.010 [−0.040, +0.016]。

这意味着本文所有关于流动的结论都是描述性的。它们刻画了信息怎么走，没有证明这样走会让辩论变好或变坏。把它们当成设计建议之前，需要一个能把流动接到结果上的实验。

这个脱钩有两种解释，现有数据分不开：可能事实组合的更新确实是事后合理化，也可能只是 VERDICT 这个三分类太粗，测不到细微的立场移动。

二、"先发言者主导终局"是口径造成的假象

按"第一个说出某事实的人"给终局组合记账，全连接 neutral 下 A 占 0.46、C 只占 0.24，看起来 A 垄断了终局。逐项分解后这个差异消失：

  • 约一半是破平局造成的第 1 轮三人并行说出同一事实时，这个口径按名字把功劳全判给 A。改成同轮平分之后，差异从 0.221 降到 0.117。
  • 第一轮的生成本身是对称的只看"A 和 C 在第 1 轮各自踩中了多少终局事实"，差异只有 0.023。材料人人可见加上第一轮并行，"谁先开口谁踩中更多"在生成层面不成立。
  • 剩下的是噪声唯一的真实残余在"只有一个人说过的事实"上，但它方向不稳定：集中在第 3 轮、由 12 个命题中的 2 个拉动（去掉后反转）、在条件之间翻符号。

教训是：在并行生成加共享材料的设定下，任何"谁先说"类统计都容易被破平局规则和有限的事实池伪造出效应。

三、星型的中心不是中转站

星型里 B 和 C 互不可见，唯一通道是中心 A。统计 C 在第 1 轮说过的 144 个事实，B 的处置是：100 个（69%）从未说过；22 个是 B 也在第 1 轮并行说了，属于两人各自从同一份材料推出的巧合；B 只在第 2 或第 3 轮说出的 22 个里，A 明确先于 B 说过的只有 14 个，也就是每场约 1 条。B 到 C 的方向更弱。

所以 B 和 C 之间看起来的内容重叠，几乎全部来自两人读了同一份材料后各自得出相同结论，而不是信息真的经过中心 A 传了过去。星型图在结构上是连通的，但这条通道实际承载的传输量很小。

四、采纳没有立场过滤

一个自然的猜想是 agent 只接自己阵营的话。检验办法是比较"同侧采纳率"和"随机底线"：底线是投递给该 agent 的事实里本方立场占多少，如果采纳不做立场过滤，实测应该约等于底线。

实测贴着或低于底线。全连接的 B（反对方）同侧采纳 0.72 对底线 0.67；星型的 A、B 是 0.29 / 0.60 对 0.32 / 0.61；全连接的 A（支持方）同侧只有 0.15 对底线 0.31，方向甚至是欠采纳本方。

结合第四节的结果可以这样理解：立场造成的隔离发生在产出环节，即每个 agent 更多地说自己的新内容、更少复述别人；而不是发生在接收环节，因为对方的事实送到之后，它并不会因为立场相反就拒绝复述。

五、取材没有立场偏倚

每场的四份证据是两支持两反对的对称设计。看 agent 说的事实里能追溯到某份证据文档的那些，三个角色引用支持类证据的比例几乎一样：支持方 41%、反对方 41%、裁决者 38%，三个都是约六成来自削弱类证据。被指派立场并不改变一个 agent 从哪份文档取材。

但要注意能追溯到证据的事实本身只占 3% 到 7%。这个低比例几乎肯定是匹配器跨来源合并能力不足（只有 12.7% 的证据事实能和 agent 说的话归并到同一簇），不是 agent 在凭空编造。所以这个数只能当下界，成分比绝对值可信。

六、采纳的事实在段落里没有特定位置

一个可能的质量代理是：认真回应的内容出现在段落开头，敷衍带过的出现在结尾。用 token 计数器测被采纳事实在采纳者输出里的相对位置，结果是 0.53 到 0.56，新事实是 0.55，自持是 0.50，全都在中间，差异不到 0.05。没有这个结构。

第十一节

11把结果串起来

上面的结果指向一个分层的看法：不应该把"多样性有没有用"压成一个总分，因为不同的旋钮作用在不同的环节上，而每个环节可以独立地成功或失败。四个环节是：

  • 一、发现团队发现了什么不同的信息？主要指标是归一化后的事实密度、事实覆盖、立场平衡。本文结果：lenses 显著提高密度，stance 把密度压回去但提高平衡。两者各有代价。
  • 二、接触与采纳信息有没有真的沿允许的边到达，并被复述？必须分别报告接触机会和条件采纳率。本文结果：拓扑主要改变接触机会（−24pp），几乎不改变条件采纳率（−5pp）。星型和全连接接触率相同，所以两者在几乎所有指标上无差别。
  • 三、留存被采纳的信息有没有留在后续推理和最终组合里？本文结果：端到端只有 2%–6%。stance 降低了入口采纳，但没有降低采纳后的留存，端到端与 neutral 相当。低采纳率不等于低整合。
  • 四、效用留下来的信息有证据支持吗，改善结果了吗？本文结果：无法回答。VERDICT 是 agent 自报立场不是质量标签，而 3%–7% 的证据溯源率只是一个严重低估的下界。

这四层依次回答"看见更多吗""传过去了吗""留得住吗""有用吗"。如果把它们合成一个总分，就无法区分一个系统是在哪一层失败的，而只有知道是哪一层失败，才谈得上改进设计。

对"中心化能吸收多种立场"这个假设的修订

星型常被当作"有整合者"的结构。但本文的星型不能这样解读：它只有结构上的中心 A，没有让 A 执行综合、限定、证据审计或最终裁决；stance 条件里 A 还固定是支持方。第十节第三条显示真正经过中心的跨枝干传输每场不到一条，第六节显示星型和全连接的人格交互几乎为零。

所以应该区分三件现在被混在一起的事：

  • 结构中心性谁连接得多。
  • 功能性整合谁被明确要求比较冲突、保留关键限定、产出共享状态。
  • 整合容量该角色能处理多少异质输入而不丢失。

现有结果反驳的是"中心节点自然会整合"，没有反驳"被赋予整合职能的中心能减少浪费性多样性"。这反而给出一个更干净的下一步实验。

第十二节

12这批数据不能说什么

  • 流动解释不了结果。见第十节第一条。本文所有关于接触率、采纳率、密度的结论都是描述性的，没有一个连接到辩论质量。
  • agent 看不到自己上一轮说了什么，所以"自持"和"留存"这两个词是错的。检查全部 648 个第 2、3 轮 turn 的提示词：0 个包含该 agent 自己上一轮的原文，而 576 个包含投递给它的同伴原文（这个对照说明检测方法有效）。提示词只有命题、完整卷宗、以及同伴的上一轮输出。
    后果是第二节里那几个指标测的东西和名字不符：自持不是"重提自己说过的话"，而是重采样稳定性——同一份卷宗再问一次，模型是否再次给出同一条事实；第七节的采纳→留存不是"守住了"，而是该事实在第 3 轮又被投递过来或被重新推导出来；事实存活同理。数字本身是可复现的，但凡是用"持续""保留""收敛"解释机制的地方都不成立，因为系统里没有能承载这些的状态。
    反过来说，这也让 自持 成了一个白拿的对照：它给出"同一份材料重问一次会重合多少"的基线，而这正是判断跨 turn 重合是不是巧合所需要的。
  • 链式的两跳需要两轮，三轮只够传一次。三个拓扑用同一套时序：每轮三人并行生成，只看上一轮投递给自己的内容。所以链式里 A 的内容到 C 要走 A|1 → B|2 → C|3，整场只有一次两跳机会，而 A 在第 2、3 轮产生的任何东西都永远到不了 C。第七节两跳只有 7 个事实，结构上就是这么来的。这不是 bug 而是设计选择（三个拓扑轮次语义一致才能比较），但它让"链式"比这个词听起来弱得多，也是链式接触率只有 42.6% 的直接原因。链式里的 A 更极端：它没有任何同伴输入，三轮提示词逐字相同（36/36 场），所以 A 的"三轮"是同一个查询采样三次。
  • 只有一个模型进入拓扑比较。辩论生成和立场标注都是 DeepSeek-V4-Flash。GLM 的 33 场只有全连接、没有星型和链式对照，未进入本文。模型之间是否复现未知。
  • 抽取不稳定，丢掉了约 5.5% 的语料，而且偏向连线少的拓扑。有实质内容（78 到 155 词）但抽取返回零个事实的 turn 共 34 个：全连接 3/324（0.9%）、星型 14/324（4.3%）、链式 17/324（5.2%）。把这 34 段各重送 3 次，22 个三次都能抽出事实、8 个两次、3 个一次，只有 1 个稳定为空，非空时中位数是 15 条。所以这不是"那些 turn 只有元话语"，而是模型抽取本身不确定。
  • 这个偏差和自变量共变，所以两类结果要分开对待。丢失率四倍集中在连线更少的拓扑上，会同时压低它们的接触率和事实数。接触率的 −24pp 比这个偏差大一个量级，站得住；但几个百分点量级的效应，比如条件采纳率上的 −5pp，不能和它分开，只应作方向性参考。人格对比不受影响，因为同一拓扑内三档人格的丢失率没有系统差异。
  • 这个缺陷没有修，是有意的。代码里已经加了空结果重试，但这 108 场是用不重试的版本跑的，没有重跑任何一场。抽取不确定意味着重跑一场会把它的每个 turn 都重抽、重新原子化、重新聚类，那 27 场受影响的辩论会处处不同于原来。27 个新抽样混进 81 个旧抽样，是"流程统一但抽样不统一"，而且差异正好和拓扑共变。要么整个语料一起重抽，要么一场都不动。这里选了后者，因为一个测量过的已知偏差，比一个为了追求公平而引入的、看不见的偏差可靠。
  • 角色和位置绑定。stance 和 lenses 条件里 A、B、C 的角色是固定的，没有轮转。只有 neutral 的位置比较是干净的，而它本身也有位置效应：发言顺序固定为 A→B→C，角色相同时 A→B 和 A→C 的采纳率仍差 3 到 6 个百分点。要估计纯粹的拓扑效应，下一轮必须做角色与位置的轮转。
  • 共享材料是所有"巧合"的来源。三个 agent 读同一份卷宗，跨 agent 的重叠天然很高，而且和真实传输不可分。所以本文一切传输结论都以投递记录为准，"实中继"口径（要求 A 明确先于对方说过）是下界。
  • 立场标注未经人工核对，由模型自标。而且约一半有立场的事实是证据层的（"E3 支持禁令"）而不是世界层的（"面纱是宗教义务"）。正反平衡和第八节的三层流动图都是混合口径，只能横向比较条件。
  • 采纳只判事实同一性，不判态度。复述对方的事实来反驳它，和复述来同意它，计为同一件事。
  • 接触率不是连续变量。三个取值 66.7% / 66.7% / 42.6% 来自三种固定接线，agent 数和轮数都没变。"接触率是起作用的线路变量"这个说法还需要一个能连续调节它的设计来检验，目前它只是对三个点的最简解释。
  • 每格 12 个命题，没有做多重比较校正。某些切片的有效样本更小：stance 条件下 A 到 C 采纳量为零的命题有 2 到 3 个，那里的成分对比只剩 8 到 9 个命题，区间很宽。第七节的第二跳只有 7 个事实，不适合做特征建模。
  • 没有外部质量标准。VERDICT 只能测方向和一致性，不能测对错。命题与证据的覆盖度这条线目前被一个工具 bug 卡住，本文没有任何"事实有用性"指标。

第十三节

13下一步与复现

五个可以立刻做的实验

  • 一、把整合职能和结构中心分开固定星型图，只操纵中心 A 是否拿到"整合者"提示词（要求它比较冲突、保留限定、产出共享状态），并轮换角色与位置的绑定。主要结果应该是保留下来的平衡覆盖度和外部评审质量，不是事实总数。这个实验在现有 12 个命题上就能做，不需要新数据集。
  • 二、预注册四层指标，不合成总分发现、条件采纳、留存、外部效用分别报告。
  • 三、加一个独立的结果变量盲评最终回答的证据覆盖度、冲突处理和来源支撑。这是回答第四层的前提。
  • 四、做一组私有信息遮蔽用来校准"同一事实晚出现"里有多少是真传输、多少是独立重推。这是第七节第二跳结论的直接检验。
  • 五、扩大命题数之后再研究"级联适应度"即哪些事实属性能预测它通过第一跳。当前两跳只有 7 个事实，样本不足。
